# 안녕하세요, 윤세호입니다 👋

게임과 웹 서비스를 만들며 사용자 경험과 기능 완성도를 함께 고민하는 개발자입니다.  
Flutter, Spring Boot, JavaScript, Unity와 Godot를 활용합니다.

## 대표 프로젝트

| 프로젝트 | 소개 | 기술 |
| --- | --- | --- |
| [rhythm-archive](https://github.com/yseho031018/rhythm-archive) | 세 가지 질문으로 하루를 기록하는 감정 다이어리 | Flutter · Dart · Drift |
| [CodingEdu](https://github.com/yseho031018/CodingEdu) | 강의·퀴즈·챌린지·커뮤니티를 제공하는 코딩 교육 플랫폼 | Spring Boot · Java · Thymeleaf |
| [arcane-barrage](https://github.com/yseho031018/arcane-barrage) | 웹 기반 로그라이트 탄막 생존 게임 | JavaScript · HTML5 Canvas |
| [unity-card-battle-mvp](https://github.com/yseho031018/unity-card-battle-mvp) | 1인용 카드 배틀 MVP | Unity 2D · C# |

## 관심 분야

- 사용하기 편한 웹·모바일 서비스
- 게임 시스템과 인터랙션 설계
- 작게 만들고 검증하며 완성도를 높이는 개발 방식

## 작업 방식

아이디어를 작은 기능으로 나누고, 직접 사용할 수 있는 형태까지 완성한 뒤 피드백을 바탕으로 개선합니다.
